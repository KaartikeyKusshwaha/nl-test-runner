# name: PHPTravels Dubai hotel search
# url: https://phptravels.net/stays
# expect: pass
Dismiss the informational demo notice only if it blocks the page. In the Destination or Hotel Name field, type Dubai and select the exact suggestion "Dubai Destination". Open Nationality, type India, and select the exact country "India" (not "British Indian Ocean Territory"). Keep the default dates and guests, then click Search Hotels. Verify the results URL contains both "/stays/dubai/" and "/IN/", and the visible results summary contains "stays found"; this also matches the empty-state text "No Stays found" when the search has no results. Do not open a hotel or submit payment.
